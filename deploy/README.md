# 获取微信小程序上传密钥

自动部署依赖微信公众平台提供的「代码上传密钥」，步骤如下：

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 进入你的小程序。
2. 左侧菜单「开发」→「开发管理」→「开发设置」。
3. 找到「小程序代码上传」区域，点击「生成上传密钥」。
4. 设置密钥有效期（建议选较长周期，如 1 年），下载得到 `private.key` 文件。
5. **不要**把 `private.key` 提交到代码仓库（已在 `.gitignore` 中忽略）。

## 在 GitHub 中配置密钥

进入你的 GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret：

| Secret 名称        | 值                                   |
| ------------------ | ------------------------------------ |
| `WX_APPID`         | 小程序的 AppID（如 `wx1234567890`） |
| `WX_UPLOAD_KEY`    | `private.key` 文件的**完整文本内容** |

> `WX_UPLOAD_KEY` 的值必须是 `.key` 文件的纯文本内容（从 `-----BEGIN PRIVATE KEY-----` 到 `-----END PRIVATE KEY-----` 的全部内容），CI 会将其写入临时文件后调用 `miniprogram-ci` 上传。

## 说明

- 该密钥仅用于「上传代码到体验版」，不能代替管理员提审发布。
- 自动上传成功后，需在公众平台「版本管理」中手动将体验版提交审核、发布。
- 若使用微信云开发，请先在公众平台绑定云环境，并在小程序「设置-云环境配置」页填写环境 ID。
